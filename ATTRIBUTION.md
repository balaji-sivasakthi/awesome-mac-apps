### Consolidation method and limits

Matched app names, official website URLs, and repository URLs across all three existing catalogs. Resolved available repository redirects and homepage aliases before inserting missing entries, and kept new rows alphabetical within their category table. Mapped source categories to this directory's categories, added Backup and Sync, converted descriptions to compact plain text, and removed display badges and tracking parameters. Pricing remains “See website” unless already established; an open-source repository does not guarantee a free prebuilt download.

For new GitHub-backed candidates, checked repository accessibility, archived/disabled state, and a nonempty default branch through GitHub's API. For website-only candidates, checked the linked official page was reachable. Excluded unavailable candidates, archived or empty repositories, detected duplicates, obvious non-Mac entries, and competing notch companions. These are metadata and reachability checks, not installation tests, exhaustive maintenance audits, or security reviews. Existing historical entries were retained.

The [consolidation manifest](data/consolidation.json) records each addition's collection, snapshot, category, project link, and verification method. Shared entries are counted only under the first source that supplied the new row; a source with zero new entries was still reviewed. Developer submission rules continue to apply to future additions.

The consolidation added **1,311 listings** and filled **21 missing source links** in existing listings. Source-link enrichment required a matching official product URL and an accessible, non-archived repository with a declared license; release-only repositories were excluded from code-source labels.
